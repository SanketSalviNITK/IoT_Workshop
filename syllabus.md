# IoT Workshop Syllabus

This 1-day hands-on workshop covers the journey from IoT fundamentals to building a cloud-connected smart system using NodeMCU and Blynk.

## 📅 Schedule

### Session 1: The IoT Ecosystem (09:00 - 10:30)
- **What is Internet of Things (IoT)?**: Definition, history, and real-world impact.
- **The Brains of IoT**: Microcontrollers (MCU) vs. Microprocessors (MPU) - understanding the difference.
- **Introduction to NodeMCU**: Hardware architecture, pinout, and onboard features.
- **Software Environment**: Setting up the Arduino IDE for NodeMCU and driver installation.

### Session 2: Interfacing and Logic (10:45 - 12:30)
- **Sensors and Actuators**: Introduction to the physical interface of IoT.
- **Basic Programming Syntax**: Variables, loops, and conditional logic for IoT.
- **GPIO Control**: Controlling Output peripherals (LEDs, Buzzers).
- **Reading Inputs**: Interfacing Digital and Analog input peripherals (Buttons, LDRs).

### Session 3: Cloud Integration with Blynk (13:30 - 15:00)
- **Introduction to Cloud Computing**: Why we need the cloud for IoT.
- **Setting Up Blynk Cloud**: Creating an account and understanding the Blynk 2.0 ecosystem.
- **The Blynk Application**: Building a mobile/web dashboard with widgets (Buttons, Gauges, Charts).
- **Connecting NodeMCU to WiFi**: Implementing the Blynk library in code.

### Session 4: Advanced Cloud Features & Alerts (15:15 - 17:00)
- **Remote Control**: Controlling hardware peripherals using the Cloud Dashboard.
- **Creating Conditional Alerts**: Setting up notifications based on sensor data (e.g., Email/Push notifications when temperature exceeds a limit).
- **Capstone Project**: Building a "Smart Home Monitor" that logs data and triggers alerts.

---
## 🎯 Learning Outcomes
By the end of this workshop, participants will:
- Differentiate between Microcontrollers and Microprocessors.
- Program NodeMCU to interact with the physical world.
- Build custom IoT dashboards on Blynk Cloud.
- Implement real-time automation and alerting systems.
