# IoT Workshop Syllabus

This 1-day workshop is designed to take participants from fundamentals to building a complete cloud-connected IoT project.

## 📅 Schedule

### Session 1: The Foundation (09:00 - 10:30)
- **Introduction to IoT**: History, Architecture, and Use Cases.
- **Hardware Landscape**: Microcontrollers (ESP32 vs ESP8266 vs Arduino).
- **Environment Setup**: Installing IDEs and Board Drivers.
- **Hello World**: Blinking the onboard LED.

### Session 2: Interfacing the Physical World (10:45 - 12:30)
- **GPIO Basics**: Digital Input/Output.
- **Analog World**: Reading sensors (Potentiometer, LDR).
- **Sensor Suite**: Working with DHT11 and Ultrasonic sensors.
- **Actuators**: Controlling Servos and Buzzers based on sensor data.

### Session 3: Communication Protocols (13:30 - 15:00)
- **WiFi Connectivity**: Connecting ESP32 to the Internet.
- **HTTP/Web Servers**: Creating a local web dashboard on the ESP32.
- **Introduction to MQTT**: The backbone of IoT communication.
- **Pub/Sub Model**: Sending data to an MQTT Broker.

### Session 4: The Cloud & Capstone Project (15:15 - 17:00)
- **Cloud Platforms**: Overview of Adafruit IO / Blynk / Thingspeak.
- **Data Visualization**: Creating real-time charts and toggles.
- **Automation**: Setting up email/phone alerts based on sensor thresholds.
- **Capstone**: Building a "Smart Environment Monitor" that logs data to the cloud.

---
## 🎯 Learning Outcomes
By the end of this workshop, participants will be able to:
- Understand the 4-layer architecture of IoT.
- Interface various sensors and actuators with microcontrollers.
- Implement wireless communication using WiFi and MQTT.
- Deploy a functional IoT dashboard for remote monitoring and control.
